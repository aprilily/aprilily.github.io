### 이렇게 일해요

- **원인부터 찾습니다.** 해금 상태가 언어와 관계없이 같게 보이던 버그는 서비스 로직이 아니라 JOIN 조건에 언어 구분이 빠진 것이 원인이었습니다. 이후로는 조건을 바꿀 때 연관 쿼리까지 함께 확인합니다.
- **동시에 들어오는 요청을 먼저 생각합니다.** 포인트 차감을 조건부 UPDATE로 바꿔, 같은 요청이 두 번 와도 잔액이 음수가 되지 않게 했습니다.
- **AI는 쓰되, 검증은 직접 합니다.** Claude로 설계안을 비교하고 코드 초안을 만들지만, 직접 빌드하고 테스트한 뒤에만 반영합니다.
- **결정은 기록으로 남깁니다.** ERD, 설계 결정, API 명세를 노션에 정리해 팀이 같은 기준으로 작업하도록 했습니다.
